# Rifas Rodríguez — Marcador de Números

App web para marcar números vendidos y descargar la imagen de la rifa.

## Uso
1. Abre la app en el navegador
2. Haz clic en los números vendidos para marcarlos con X roja
3. Presiona **Descargar Imagen** para obtener el PNG listo para publicar

## Deploy local
Abre `index.html` directamente en el navegador (o usa Live Server).

## Deploy en Vercel
Conecta este repositorio en [vercel.com](https://vercel.com) y se despliega automáticamente.
